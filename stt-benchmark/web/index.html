Understanding the results

WER = (substitutions + deletions + insertions) / reference words. CER measures character errors, excluding whitespace and preserving Vietnamese accents. Vietnamese WER uses whitespace-separated tokens. Common metrics cover samples that succeeded across all models. RTF = processing time / audio duration.

P95 uses the nearest-rank percentile. Simulated lag runs from the end of a chunk until its result is available, including a single-worker queue. First-text time runs from the start of the audio until the first nonempty result. These measurements exclude microphone capture, browser network delays, and application endpoint detection. Compare results using the same language and input protocol.

RTF excludes model loading. There is no separate warm-up, so the first sample may be slower. API processing includes upload and provider response time. Transformers processes long files in 30-second blocks; CTC uses greedy decoding without an external language model. Configurations and protocols are saved in the JSON report.
